Notes on what CAPSULE can do. This page has no domain, no certificate and no host. It is served by the network it talks about.

Why CAPSULE?

First entry

I built CAPSULE because I did not want to trust anyone.

Every service I used to send a file said it was encrypted. All of them could still read my files. That is the part that gets leaked, scanned and sold. So the question is not whether something is encrypted. The question is who has the key.

Putting a page online works the same way. You rent a domain. You get a certificate. Someone hosts the bytes. Three companies, and any of them can take your page down. All three send a bill.

I wanted something simpler. A server should be able to hold my file without being able to open it. So the file is encrypted before it leaves my machine, and the key never goes to the server. It travels in the part of a link that browsers do not send. The relay stores bytes it cannot read. There is no account.

I care about this because information should move freely. Right now it does not. Someone decides if your page stays up, if your file is allowed, if your name is still yours next year. I wanted to remove that someone.

I should be honest about where it is. The network is small, so the protection is small. Mixing traffic through relays that one person runs protects nobody, and that is close to what exists today. It gets better when more people run relays. Nothing else fixes it.

That is why this is a page and not a README. It works, and you are reading it through the thing it describes.
