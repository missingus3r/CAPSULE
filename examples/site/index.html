Capsule

Nobody sold you this address.

You are reading a page that has no DNS record, no certificate and no hosting bill. Its name is not registered anywhere, because its name is a public key — and the only thing that can publish under it is whoever holds the matching private one.

The relay that handed you these bytes cannot read them. It stored one encrypted blob and a signed record saying where to find it. It does not know what this page says, who wrote it, or that you asked for it.

How this page reached you

The name
An Ed25519 public key, written as the label before .capsule. Losing the key loses the site; nobody can hand the name to someone else, because there is nobody to ask.
The bundle
Every file of this site packed into one capsule and encrypted before it left the machine that published it.
The record
A signed pointer from the name to the capsule, gossiped between relays. A relay can refuse to carry it. It cannot forge one.
The rendering
Your browser did not load this page — the extension rebuilt it. Stylesheets and images became data: URLs, everything pointing at the open web was removed, and the result landed in a sandboxed frame with connect-src 'none'.
