Three things this page cannot do.

Each check below is a real attempt, left in the source on purpose. A .capsule site is untrusted content, and the viewer treats it that way.

Check 1 — the tracking pixel

An image hosted somewhere else

The markup asks for an image on another server. Loading it would tell that server your IP address, the time you read this, and roughly where you are. Right below this line is where it would appear.

Expected: nothing loads, and the viewer reports one blocked external resource.

Check 2 — the script

A script that rewrites the page

The script did not run. This sentence is exactly as it was written, and no code on this page has touched it.

Expected: the sentence is unchanged. Turn scripts on in the viewer and reload to watch it change — that is what the setting costs.

Check 3 — the link out

A link that leaves CAPSULE

Following it means making an ordinary request to an ordinary web server, with everything that implies. So it is not a link the page can follow on your behalf — it is a click you have to confirm.

https://example.org/

Expected: a confirmation first, naming the address, before anything leaves.

Link to its own pages
